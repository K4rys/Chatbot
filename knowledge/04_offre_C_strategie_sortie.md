# Offre C · Valorisation — note de stratégie de sortie

On chiffre 2 à 3 scénarios dans le modèle de bilan. Toute commercialisation pour le compte du
client relève d'une agence titulaire de la carte T : SGO IMMO ne la propose pas.

## Synthèse
Scénario recommandé ; CA, marge (€ et %), durée, principal risque ; première action
(ex. mandater un géomètre pour le plan de division avant le __).

## 1. Point de départ
Bien et situation ; contraintes (urbanisme, occupation, copropriété, financement, date butoir) ;
objectif du client (maximiser la marge / sortir vite / limiter les fonds propres).
L'objectif du client détermine le scénario : ne recommande pas le scénario à la plus forte
marge s'il immobilise des fonds propres que le client n'a pas ou dépasse sa date butoir.

## 2. Scénarios comparés
Typiquement S1 vente en bloc, S2 découpe / division, S3 vente après travaux. Critères :
description, autorisations nécessaires, CA, coûts supplémentaires, marge nette, marge / CA,
durée, fonds propres mobilisés, rentabilité des fonds propres, risques principaux, note /10.

## 3. Scénario retenu : grille de prix
Par lot : nature (T2, terrain à bâtir…), surface, prix cible, €/m², prix plancher,
cible acquéreurs (primo, investisseur, CCMI).

## 4. Plan d'actions
Plan de division / bornage (géomètre) ; dépôt DP / PA / EDD modificatif (client, architecte,
notaire) ; viabilisation / travaux (entreprises, BET) ; diagnostics et attestations de surface ;
mise en commercialisation (client ou agence titulaire de la carte T). Pour chaque action :
intervenant, échéance, coût estimé, statut.

## 5. Commercialisation : principes
Canaux : vente directe par le client, mandat(s) d'agence, partenaires constructeurs et courtiers.
Ordre de mise en vente des lots et règle de baisse de prix (ex. −3 % après 45 jours sans offre ferme).
Indicateurs : contacts, visites, offres, délai moyen de vente.
